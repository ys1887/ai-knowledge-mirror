# 00_inbox（仮置き）

行き先がまだ決まらない情報の仮置き場所です。PARA の分類外の例外として、ルート直下に置きます（2026-11-16、本人の決定で新設。Bonochin の個人ナレッジベース設計を参考にした）。

## 置いてよい物

- どのフォルダに入れるか、その場では判断がつかない情報の一時メモ
- 行き先は決まったが、置き場所の新設や移動に本人の許可が要り、待ちになっている物

## 置かない物

- 秘密情報の値（パスワード、APIキー、トークン、復旧キー）
- 連携サービス（Gmail、Google Calendar など）の本文の写し
- 行き先が決まっている物。決まっているなら、最初からそこへ書きます。ここは「迷ったら全部ここ」の場所ではありません

## 書き方

- ファイル名は `YYYY-MM-DD_主題.md` の形にします
- 冒頭に、出どころ（いつの、どの作業や会話で出た物か）と、置いた者を書きます

## 整理

- 振り分け先が決まったら、正しい場所へ移し、こちらは消します。写しを両方に残しません
- 整理はコンテキスト巡回が担います（手順書の手順 9）。巡回は、振り分け先が判断できる物を正しい場所へ移し、判断できない物は残して、実行記録に件数と主題を残します
- 本人は直接消したり移したりして構いません
