# エッダ（Edda）コーパス

## 出典と取得（2026-11-19）

- 詩のエッダ原文：Edward Pettit 編『The Poetic Edda: A Dual-Language Edition』（Open Book Publishers、2023年、CC BY-NC 4.0）の PDF（Internet Archive 収蔵）から、古ノルド語のテキストページだけを機械的に抽出した。序文、英訳、注釈は除いてあるが、詩の末尾に校訂メモ（異読）の一部が残る箇所がある
- 英訳2点は Project Gutenberg から取得（gutenberg.pglaf.org 経由）
- 散文エッダ原文：Finnur Jónsson 校訂『Edda Snorra Sturlusonar』（Reykjavík、Sigurður Kristjánsson、1907年）の Internet Archive スキャンの OCR テキスト。表紙と蔵書印のノイズを取り除き、行末のハイフネーションを接続した。編者の序文と注も含むため、OCR 由来の誤読があり得る

## 著作権と条件

- 両エッダの原文：パブリックドメイン
- Bellows 訳：訳者は1939年没。権利切れ
- Anderson 訳：訳者は1936年没。権利切れ
- Finnur Jónsson 校訂：1907年刊行、編者は1934年没。日米とも権利切れ
- Pettit 校訂版：CC BY-NC 4.0。非商用に限り、出典を明記すれば複製と翻案ができる。このコーパスの利用は非商用の範囲内

## 入れていないもの

- 散文エッダの Brodeur 英訳（1916年）：米国ではパブリックドメイン（1916年刊行）で Wikisource に全文があるが、訳者 Arthur Gilchrist Brodeur の没年が1971年のため、日本では保護期間内（死後70年で2041年末まで。戦時加算を入れるとさらに先）。そのため Drive コーパスには入れていない（取得と組み立てまで進めたエイダ側のローカル控えも、本人の指示で削除済み）。英訳は Anderson 訳でまかない、原文の言い回しは Finnur Jónsson 校訂の原文で確認できる
- heimskringla.no と is.wikisource の散文エッダ本文は Guðni Jónsson 校訂（1974年没）で権利が残るため使っていない。1848年の Arnamagnæan 版は OCR の質がコーパス向きではない
