# sherlock-holmes（シャーロック・ホームズ原文コーパス）

Arthur Conan Doyle のシャーロック・ホームズ正典、全60作（長編4・短編56）の英語原文を、AIが参照しやすい形で保管するフォルダ。

配置日： 2026-11-17（エイダが配置）

## 構成

- `index.md` — 全60作の索引（英題・邦題・形式・収録巻・初出年・ファイル名・語数）。参照はここから始める
- `works/` — 本文。1作1ファイルのプレーンテキスト（UTF-8）。各ファイルの先頭に出典を示す1行を付けてある

## 出典と権利

- 出典は Project Gutenberg のテキスト（各作品の Gutenberg ID は索引の元データと各ファイル先頭に記載）。底本は著作権切れの古い刊本
- ドイルは1930年没。原作の著作権は日本・イギリス・EU・アメリカすべてで満了しており、パブリックドメイン（日本では1991年頃に消滅、アメリカでは最後の短編集が2023年1月1日に満了）
- 翻訳は別の著作物なので、このフォルダには原文（英語）のみを置く

## 版についての注記

- 「The Adventure of the Cardboard Box」は版によって収録巻が異なる。今回の底本では『The Memoirs of Sherlock Holmes』（米国 Harper 版系）に収録され、『His Last Bow』は7編構成。合わせて正典56編が重複なく揃っている
- 『The Case-Book of Sherlock Holmes』の底本は、収録順が英国初版と異なる版（The Illustrious Client から始まる）。索引の並びは正典の刊行順にそろえてある
- 表記は底本に従う（例： Memoirs の「The Stockbroker's Clerk」は一語綴り）

## 含まれていないもの

- 正典外の小品「The Field Bazaar」（1896）、「How Watson Learned the Trick」（1924）は入れていない
- 各巻の序文・目次などの前付けは、作品ファイルには含めていない（巻単位のファイルはエイダのワークスペース控えにある）

## 使い方（AI向け）

1. 質問に関係する作品を `index.md` で特定し、その作品のファイルだけを読む
2. 筋・固有名詞・年代は原文で裏を取ってから答える。記憶だけで断定しない
3. 全文を毎回読まない。必要な作品・必要な箇所に絞る
