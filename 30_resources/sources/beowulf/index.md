## 出典と取得（2026-11-19）

- 原文は Project Gutenberg に収録がないため、Wikisource（en.wikisource.org）の「Beowulf (Wyatt)」の校正済みテキストから機械的に抽出した。行番号、脚注マーカー、写本の葉番号は除去してある。フィンスブルグの戦いの断片も含む
- 章の番号付けは Wyatt 版に従い、標準的な章番号とずれる箇所がある。行の範囲は1〜3182行まで連続していて欠落はない（Wikisource の目次で確認）
- 抽出は機械処理のため、編集上の記号などが多少残る可能性がある。本文の校合が必要なときは底本に当たること
- 英訳は Project Gutenberg から取得（gutenberg.pglaf.org 経由）。Gummere 訳は韻文訳で、Harvard Classics に収められた代表的なパブリックドメイン訳
