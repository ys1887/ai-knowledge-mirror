# ヘレンニウスへの修辞学書（Rhetorica ad Herennium）コーパス

ラテン語の修辞学書、全4巻。紀元前80年代の作で作者不詳（長くキケロの作とされてきた）。「記憶術」で知られる場所法（loci 法）の最古のまとまった記述は、第3巻16〜24章にある。

## 出典と取得（2026-11-19）

- 底本は Friedrich Marx 校訂の Teubner 版（Leipzig、1923年印刷）
- ラテン語 Wikisource（la.wikisource.org）から取得した。同サイトの出典表示はチューリッヒ大学の Corpus Corporum
- 取得時に、Wikisource の章見出し記法（==数字==）だけを通常の数字に置き換えた。本文は原文のまま
- Project Gutenberg には収録がない。Perseus の標準ラテンコーパス（canonical-latinLit）のキケロ全集60点にも含まれていないことを確認済み

## 著作権

- 原文：パブリックドメイン（古代の著作）
- Marx 校訂版：編者は1928年没。権利切れ
- 英訳の標準である Caplan の Loeb 版（1954年）は現代訳として権利が残るため入れていない。LacusCurtius は「米国では著作権の更新漏れでパブリックドメインになった」として全文を公開しているが、日本ではその扱いにはならない
