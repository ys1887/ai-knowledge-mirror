
## 六 易者と易者

明治三十年(一八九七)、嘉右衛門はすでに六十六歳になっていた。十九年に刊行した『高島易断』の初版は全十巻だったが、以後新しい占例が出来てくる上に、辞の解釈も一層精緻さを増して来たので、日清戦争中の二十七年に全十七冊に増補して公にし、間もなく上下二巻にまとめ、計二千頁以上の大冊となった。

その字数は百万字以上になっている。彼はこれを漢訳して、 清国朝野の賢士に贈ろうと思い立ち、槐蔭・斎藤真男に依頼して翻訳を進めていたが、(これはその後三年かかって彼の古稀の年に完訳を贈ることが出来た。)

啓蒙はもっと、「近きより遠きに及ぼす」要があると考え、東京中の易者を一堂に集め一席の講演を行うことにした。

客観的に見れば一種の"旦那の義太夫"であるが、彼の同学・同好に注いだ愛情は極めて深いものだった。(この時彼は出席者全員に『高島易断』を贈った。)

「今日此堂に会せられたる諸君は、 皆余と同じく易道を好み、 天命を楽しむの君子なれば、世間通常の士と同視すべからず。蓋し易道は神聖深奥の学、占筮は至誠感通の術にして、骨肉の子孫と雖も之を伝えんとして伝う可らず、唯器量其人を得て能く之を継続せしむるの外、他の方法無し。世に学者尠からずと雖も、能く斯の道を嗜み、其の妙味を知る者に至りては未だ其の多きを見ざるなり。是を以て余は常に天性禀賦の余と其の趣向を同一にする人あらば、すなわち斯の道を伝えんことを欲せり。」

と呼びかけ、 易が万古に傑出した四聖人の手によって大成した学術で、卜筮を経験せぬ学者は語るに足りないと痛論し、卜筮を行う諸君こそ我が後継者であるから、この『高島易断』を贈るのだが、それについては二つの注文がある。その一つには易経二冊(上下)を暗誦記憶して貰いたい、二つにはこの書を読んで易学の深奥をきわめ、占筮の的中したものがあったらこれを筆記しておいて、私の所まで送って貰いたい。

そうすれば自分はそれを編集し、一種の天命学とも称うべきものを大成し、斯の道の光輝を全世界に煥発したいと思う。-このようにして成功すれば、あまねく世人をして天命の畏るべきと、道徳の基本とを知らしめ、凶を避け吉に赴かしめることが出来ると思う。

と期待を述べ、広い心を以て"売上"についても触れた。

「そもそも易は未然を知り、天命を楽しむの道なれば、その学術に於ける、義を精しくし神に通ずるの妙境に到達するときは、所謂"学ぶや禄其中に在(学也禄在其中) ものにして、一家の生計の如きは復た念頭に掛くるを要せざるなり。然りと雖も学術修業中は聊か売トして其の生計を営むも、亦やむを得ざる権道なり、敢て不可なきのみならず」

と言い、声をさらに大にして、

「或は大いに世に益する所のものあらん。凡そ人の世にあるや。貴賤男女を問はず、進退挙措に就きて疑懼憂悔の念無き能はず、今や来つて占筮を請う者は、皆此の疑懼憂悔ありて其の進退挙措を決すること能はざるものなれば、心配の相談人となり、之に対するには懇篤親切を以てし、其の請う所の事を占筮に問うて将来の方向を誤らざらしむるを要す」

と、易者の心得を説いた。

「占者各自其の業務に勉励し、 言行誠実を旨とすべし…出処起赴人にはじざるの一大精神を有ち、自彊して息まざるべし。斯くの如き者天下に輩出するときは、易道大いに世に崇信せられ、易者は常に世人に倚頼せらるるに至るべし」

と諭し、

「人をして神明の厳在を確認せしむるは、易に如くなし。又天命を立どころに受け、以て世事に利用するは易を措きて他に術あることなし」

とその効用を讃し、次いで最も大切な、いうなれば彼の大秘伝とも称すべきことを述べている。

「…然るに世の易を説く者、至誠を以てせずして単に学理を以てするあり。故に的中あり又不的中あり、是れ俚諺に"当るも八卦、当らぬも八卦"と云う所以にして、遂に世人に之を贅物視せらるるに至る」

と慨嘆し、それは易者でありながら真に易を信じないで、天命を知らず、天命を畏れず、ややもすれば大人に狎れ聖人の言を侮る易者自らが招くところだ、と痛いところを突いている。

また、維新後の日本全体が、長い鎖国の夢から醒めたせいで外の知識(特に形面下の学同)の吸収に急で、深奥微妙な易学を研究する暇がなくなった。-その証拠には大学という形而上形而下の学術を網羅具備しているべき機関が"易学"の教育をやらないことである。

これは天下後世のため実に嘆かわしい。と嘆息し、易道を深く学び世のため国のために役立てようではないかと呼びかけた。この時、彼の講演を聞いた人たちの中で、心ある者は以後大綱山の邸にたびたび出入し、ことに春四月嘉右衛門主催の孔子祭に招待され、一緒に桜を見一緒に酒を飲んだりした。

これらの人たちは、「高島先生の講演を聞き、お邸へ出入し、講義を拝聴した」と言っても、高島姓を名乗ったりはしない。後年神戸の湊川附近に居住して「高島先生直門」という看板を掲げて実占していた橋本中道氏は、神奈川県の小学校教員だったが、この講演を機会に入門、いわゆる「書き役」など勤めながら勉強したものらしい。

嘉右衛門が、「後世の易者」に期待したことは大きく、「果して真の易者が居るか」という占題で筮した挿話もあるくらいである。

それは、例の進歩的政治家、得庵・鳥尾小彌太居士と語り合った、明治十八年のことだが、ここに記しておこう。得庵居士曰く。

「天下は広い、人材も亦多い筈である。一人二人傑れた人士が居ない筈はない」

呑象曰く。

「自分のように易理を玩んで二十有余年になる者にして、其の感通の度といえば僅かに沢山咸 昔から易を学んだ人達のことを通観してみても、孔子以来、真に神明に酬酢した者は多くないようだ。だから今日のように現理のみを主にする時代に、そんな傑れた人物があるとは思えない」このような意見の相違から、では真の易者の有無を一占によって決しようではないか。……と二人で筮し、得庵が得たのは水沢節(三二)の三爻だった。呑象が得たのは風地観(一三)の上爻である。

呑象は自身の得た卦から、「観は大艮で鬼神を祭祀する卦だから、この問筮事項に叶った卦が出ている」とまず認め、

「人間は変詐百出でアテにならねえが、天道には変がない、この五・上爻の陽明・高尚がそれだ。若し人にして陽明・高尚な天道を承けられる人があれば、三爻の人位(易では五上爻を天位とし、三四爻を人位とし、初二爻を地位と見る)に変があって然るべきだ。それがそこに起きず、上爻に変を見るのは真の易者が存在しない証拠。だから今はまだ出ていないと見る。しかしいつまでも出ないというのでなく、上爻が示す未来には、易術を以て神明に通じることの出来る者が必ず現れるだろう」

と判断した。得庵も、

「なるほど、観の上爻というところから見れば、神明に酬酢している者は居ないという表示だ。わしの得た節の六三もその通り、ほんとの易者をいま求めることは、霜月に春の花を求め、初夏に新米を求めるような気の早い話だ」

と同意した。

いま誰かが同じ占題で、「真の易者ありや」を求めても、七十年前に呑象と得庵が求めて得られなかったように「未だ居ない」という答が出るかも知れない。


「瞑目して、 気息を殺し、 其占はんとする事を一心専念する。是なり。此の如くするときは、邪思妄想自ら去り、寂然として動くことなし。是れ予が積年経験する所にして、此の如くせば、鬼神の感応ある疑うべからず。所謂陽気の発する所、金石亦透る。精神一到何事か成らざらん。一心専念の力、能く鬼神に貫徹するを得べし。而して其の気息を殺し、次息の将に継んとする瞬間に、拇指を以て筮竹を分つ。是れ此の卦(沢山咸)の初爻に其ノ拇ニ咸ズ、とある是れなり。又鬼神の往来絶えざることは、四爻に(初の応爻)憧々トシテ往来ス、朋爾ノ思ヒニ従フ、とある是れなり。此の両爻、一般の例に依り、其の拇を足の拇指として其の往来を初四の応に取ると雖も、卜筮感通の理、隠然其の中に寓す、易の微妙なる此の如し。」

と言っている。

咸卦に取象して筮儀を説いたところに、いわゆる"高島易"の大秘伝があるものと思う。

寝ころんでやっても、握りキンでやってもアタルから、厳粛荘重などこけオドシを真似なくてもいいという人は論外である。

筆者は、未熟のため「津々として指頭に感動するもの」を受ける境地は、一度も味わったことがないが、それを感じるようになったら「百占違わず」になりうるのではないかと思う。

ただし、津々と指頭に感動するものによって、卦を正しく受け取ることが出来るようになると思えるからである。

つまり、その感動によって清明の心が得られ、読卦観象が的確になるのだと思う。この間の消息はなかなかむずかしい。

嘉右衛門から直接口授をうけ、あるいはその探筮を目のあたりした人は、その点幸せである。
