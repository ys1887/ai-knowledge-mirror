# EX_SIMPLE 出力テンプレート

このテンプレートは、EXTRACT モードで

* 本卦
* 変爻

を読み、最後に解釈をまとめる簡潔版です。

自然文だけで流さず、必ず以下の見出し骨格を維持してください。

---

## 出力ルール

* `## 本卦（卦番号＋卦名）` を置くこと。
* 次に `## 変爻（爻位）` を置くこと。
* 最後に `## 総合解釈` を置くこと。
* 見出し構造を崩さないこと。
* 自然文だけで流さず、必ず節ごとに分けること。
* 本卦では、`quotes_honka.md` の該当卦ブロックを、該当見出しから次の卦見出し直前までのまとまりとして扱うこと。
* 変爻では、`quotes_koji.md` の該当爻ブロックを、該当爻見出しから次の爻見出しまたは次の卦見出し直前までのまとまりとして扱うこと。
* 卦辞・彖伝・大象伝・爻辞・小象伝を個別見出しに分けないこと。
* 本卦解釈では、質問文・背景事情・現状への当てはめを書かないこと。
* 変爻解釈では、質問文・背景事情・現状への当てはめを書かないこと。
* 問いへの答え、助言、今後の見通し、最終判断は `## 総合解釈` にのみ書くこと。

---

## 本卦（卦番号＋卦名）

`quotes_honka.md` から、該当する本卦のブロックをそのまま示すこと。

ここでいう「そのまま示す」とは、少なくとも以下の方針に従うこと。

* 該当卦見出しから次の卦見出し直前までの範囲を、一つのまとまりとして扱うこと。
* Markdown の引用記法 `>` を保ったまま示すこと。
* 原文・読み下し・説明文・`（占）` を、source にある順序をできるだけ保ったまま示すこと。
* source にない文を、引用本文の一部として補わないこと。
* 卦辞・彖伝・大象伝を、別々の小見出しに分割しないこと。

### 本卦解釈

`takashima_interp_**.md` に基づいて、本卦全体の解釈を書くこと。

ここでは、以下を `takashima_interp_**.md` の論旨に沿ってまとめること。

* この卦がどのような時を示すか
* その時の基本原理は何か
* その時に見える含意や警戒は何か

質問文・背景事情・現状への当てはめを書かないこと。
この節で助言・予測・最終判断を書かないこと。
`quotes_honka.md` に基づく要約や解釈を、この節に混在させないこと。

---

## 変爻（爻位）

`quotes_koji.md` から、該当する変爻のブロックをそのまま示すこと。

ここでいう「そのまま示す」とは、少なくとも以下の方針に従うこと。

* 該当する爻見出しから次の爻見出しまたは次の卦見出し直前までの範囲を、一つのまとまりとして扱うこと。
* Markdown の引用記法 `>` を保ったまま示すこと。
* 原文・読み下し・説明文を、source にある順序をできるだけ保ったまま示すこと。
* source にない文を、引用本文の一部として補わないこと。
* 爻辞・小象伝を、別々の小見出しに分割しないこと。

### 変爻解釈

`takashima_interp_**.md` に基づいて、変爻全体の解釈を書くこと。

ここでは、以下を `takashima_interp_**.md` の論旨に沿ってまとめること。

* 今回どこが焦点になっているか
* その位置で何が問題になるか
* 何を戒めるべきか
* その位置の含意は何か

質問文・背景事情・現状への当てはめを書かないこと。
この節で助言・予測・最終判断を書かないこと。
`quotes_koji.md` に基づく要約や解釈を、この節に混在させないこと。

---

## 総合解釈

`takashima_interp_**.md` に基づいて、本卦全体と変爻全体を合わせた今回の問いへの答えをまとめること。

ここでは、以下を `takashima_interp_**.md` の本文に立ち返り、高島の論旨・警戒・勧めを踏まえて、今回の問いに対してしっかりまとめること。

* 今回の問いに対する結論
* 進んでよいか、控えるべきか
* 慎重条件や留保条件
* 何を軸に判断すべきか

結論はここで集約すること。
本卦解釈や変爻解釈の言い換えだけで終わらないこと。
本卦や変爻の各節で散らした判断を繰り返しすぎないこと。
`quotes_honka.md` や `quotes_koji.md` に基づく要約や解釈を、この節に混在させないこと。

---

## 引用ルール

* 本卦では `quotes_honka.md` の該当卦ブロック全体を扱うこと。
* 変爻では `quotes_koji.md` の該当爻ブロック全体を扱うこと。
* source にある Markdown の引用記法 `>` を保つこと。
* source にある原文・読み下し・説明文・`（占）` は、順序をできるだけ保つこと。
* 引用していない文を、引用のように見せないこと。
* 原文が確認できない場合は、推測で補わないこと。

---

## 省略条件

* 変爻がない場合は、`## 変爻（爻位）` と `### 変爻解釈` を出力しないこと。
* `変爻：なし` のような補助行も出さないこと。

---

## 禁止事項

* `### 卦辞` `### 彖伝` `### 大象伝` `### 爻辞` `### 小象伝` を出さないこと。
* 本卦解釈・変爻解釈で質問文・背景事情・現状への当てはめを書かないこと。
* 本卦解釈・変爻解釈で助言・予測・最終判断を書かないこと。
* 総合解釈で本卦解釈・変爻解釈の言い換えだけを繰り返さないこと。
* source のまとまりを崩して、一部だけ抜き出したり順番を入れ替えたりしないこと。
