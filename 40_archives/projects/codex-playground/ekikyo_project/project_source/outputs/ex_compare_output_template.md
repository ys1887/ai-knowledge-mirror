# EX_COMPARE 出力テンプレート

このテンプレートは、[MODE:EXTRACT] かつ [TEMPLATE:EX_COMPARE] のときに使う。

目的：
- 複数候補を比較して、順位と推薦を明確に示すこと
- できるだけ同じ構造で安定して出力すること
- 各候補では、原則として引用を根拠に順位理由を書くこと

全体ルール：
- 見出しはこのテンプレートに従うこと。
- 勝手に見出しを増やしすぎないこと。
- 各候補ごとに、原則として `quotes_koji.md` から **爻辞または小象伝を少なくとも1つ** 引用すること。
- 必要なら `quotes_honka.md` から本卦の卦辞を短く補助的に引用してよい。
- 引用だけで終わらず、その引用を根拠に順位理由を書くこと。
- 解釈補強が必要な場合は `takashima_interp_**.md` を用いてよいが、逐語引用はしないこと。
- 序卦伝と文言伝は、原則として独立引用しないこと。必要がある場合のみ、順位理由やまとめの補助として簡潔に参照してよい。
- 候補数は固定しないこと。順位・候補別解釈・まとめ表は候補数に応じて増減すること。
- 最後は `総合解釈` ではなく、必ず `まとめ` で終えること。

---

## 核心・結論

- 最有力候補を最初に明示すること。
- 上位候補の強みと、下位候補の弱みや注意点を2〜4文でまとめること。
- 必要なら「今は避けたほうがよい候補」にも一言触れてよい。
