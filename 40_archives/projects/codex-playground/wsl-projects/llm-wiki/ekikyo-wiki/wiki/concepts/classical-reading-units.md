# Classical Reading Units

**ページ目的:** この wiki で繰り返し参照する古典層の単位と、その扱い方を簡潔に整理する。

## 主たる読みの単位

| 単位 | 役割 | この wiki での扱い |
| --- | --- | --- |
| 卦辞 | 卦全体の主題を示す核 | 個別卦ページを作る際の主軸候補 |
| 彖伝 | 卦辞の展開と時義の補強 | 卦全体の論旨整理に使う |
| 大象伝 | 卦全体の象意と行い方 | 卦全体の姿勢や構図を補う |
| 爻辞 | 変爻ごとの局面判断 | 変化点を見る主たる単位 |
| 小象伝 | 爻辞の補足 | 爻辞の読みを補強する |

`ekikyo_project` と `ekikyo` repo の両方で、まずこの層を本文として扱い、他の層は補助扱いにする構えが明示されている。

## 補助層

| 単位 | 主な役割 | 注意点 |
| --- | --- | --- |
| 序卦伝 | 卦の並びと推移を見る | 主軸にせず、流れの補助に留める |
| 文言伝 | 乾・坤の補助読解 | 乾為天・坤為地に限って使うのが安全 |
| 繋辞伝 | 易全体の原理背景 | 卦辞や爻辞の代わりにしない |

## 引用層と解釈層は分ける

- `quotes_honka.md` と `quotes_koji.md` は引用層であり、原文・読み下し・説明付き block の扱いが固定されている。
- `takashima_interp_**.md` や `assets/takashima/` は解釈層であり、引用 block と混同せずに読む。
- 今後個別卦ページを作るときも、「何を引用として固定し、何を解釈として要約するか」を分けて書く必要がある。

## 現時点での使い分け

- 高島系 EXTRACT の運用理解には、まず引用層と解釈層の分離を優先する。
- Obsidian 側の `序卦伝` や `六十四卦一覧` は、学習用・補助用の入口として有用だが canonical quote source そのものではない。
