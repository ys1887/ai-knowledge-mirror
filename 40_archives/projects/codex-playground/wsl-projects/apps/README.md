# apps

小さなアプリをまとめて置くためのフォルダです。

## 構成

- `epub-splitter`
- `ameblo-md-downloader`
- `ekikyo-md-downloader`
- `iching-calculator`
- `iching-source-viewer`

## 役割

- `epub-splitter` は EPUB を分割するためのツールです。
- `ameblo-md-downloader` は Ameblo の Markdown 取得用です。
- `ekikyo-md-downloader` は ekikyo 関連の Markdown 取得用です。
- `iching-calculator` は易経の占断計算用アプリです。
- `iching-source-viewer` は易経の原文・解釈参照用ビューアです。
