# 断易（易経）卦計算プログラム

## 概要

このプログラムは、ユーザーが入力した本卦の2進数表記と変爻の位置に基づいて、断易（易経）の之卦、互卦、裏卦、綜卦を計算し、結果を表示するPythonプログラムです。

## 動作環境

*   Python 3.12 (またはそれ以上)
*   外部ライブラリ: `json` (Python標準ライブラリ)

## 使い方

1.  **必要なファイル:**
    *   `duanyi.py`: プログラム本体
    *   `base_hexagrams.json`: 卦のデータ (JSON形式)
    *   `run_duanyi.bat`: (Windows用) プログラムを起動するためのバッチファイル

2.  **実行方法:**
    *   Windows: `run_duanyi.bat` をダブルクリックします。
    *   macOS/Linux: ターミナルで `python duanyi.py` を実行します。

3.  **入力:**
    *   **本卦の2進数表記:** 6桁の0と1で構成される文字列を入力します (例: `101010`)。
    *   **変爻の位置:** 1から6の数字をスペース区切りで入力します (例: `2 5`)。変爻がない場合は、何も入力せずにEnterキーを押します。

4.  **出力:**
    *   **本卦:** 入力された本卦の番号と名前が表示されます。
    *   **之卦:** 変爻がある場合、之卦の番号と名前が表示されます。
    *   **互卦:** 互卦の番号と名前が表示されます。
    *   **裏卦:** 裏卦の番号と名前が表示されます。
    *   **綜卦:** 綜卦の番号と名前が表示されます。

## ファイル構成

*   `duanyi.py`: メインのPythonスクリプト。卦の計算と結果表示を行います。
*   `base_hexagrams.json`: 64卦の基本データ（番号、名前、2進数表記）を格納したJSONファイル。
*   `run_duanyi.bat`: Windowsで `duanyi.py` を簡単に実行するためのバッチファイル。

## 使用ライブラリ

*   `json`

## 注意事項

*   入力値は適切に検証されますが、正しい形式で入力してください。
*   JSONファイル (`base_hexagrams.json`) が存在しない場合、または形式が不正な場合は、エラーメッセージが表示されてプログラムが終了します。
