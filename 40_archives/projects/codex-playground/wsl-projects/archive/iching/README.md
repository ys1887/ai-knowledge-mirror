# iching

このリポジトリは、易経関連の複数リポジトリを履歴付きで統合した親リポジトリです。

## 構成

- `iching-div`
- `iching-sdk`
- `ekikyo-div`
- `ekikyo-sdk`
- `apps/iching-calculator`
- `apps/iching-source-viewer`
- `data/iching-hexagram-db`

## 配置の考え方

- `apps/` はアプリ寄りのものを置きます。
- `data/` は共通データ資産を置きます。
- `apps/iching-source-viewer` は本卦・変爻などの原文を全文表示するビューアです。
