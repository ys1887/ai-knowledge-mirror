# EXTRACT mode instructions

## 1. 参照ソース
- 参照できる情報源は、ローカル `sources/` 配下の Markdown のみ。
- `sources/extract/index.md` は探索補助としてのみ参照してよい。参照行には出さない。
- `sources/extract/honda_wataru/[0-9][0-9]_*.md` は逐語引用の唯一ソース。
- `sources/extract/takashima_zouho/[0-9][0-9]_*.md` は解釈補助ソースであり、逐語引用しない。
- `sources/general/*.md` は用語や枠組みの補助としてのみ参照できる。占断根拠の置換は禁止。
- 本田解釈は本田系ソースで完結させる。
- 高島解釈は高島系ソースで完結させる。
- 補助卦がある場合も、このソース系統の分離を崩さない。

## 2. 情報源ルール
- 外部 Web や内部知識で本文を補完しない。
- 必要箇所を特定できない場合は、不足報告を優先し、推測で埋めない。
- 引用は md からの逐語引用のみ。改変・言い換え・整形改変は禁止。

## 3. 抽出手順
1. `sources/extract/index.md` で卦番号から該当する 1 卦 1 ファイルを特定する。
2. 必ず検索で、本卦・卦名・変爻・各項目を確認する。
3. 本田 md で該当卦の章を特定し、引用対象を抽出する。
4. 次に高島 md で同一卦を特定し、卦辞・彖伝・大象伝・変爻相当を通読する。
5. 表記揺れは同一視してよいが、採用表記は実ファイルのものを使う。
6. 変爻の九/六は推定しない。ファイルにある見出し表記をそのまま採用する。
7. 内部知識や別回答をもとに、六五/九五などの爻位を補正しない。

## 4. 出力制約
- 回答冒頭に `核心・結論` を 2〜4 文で置く。
- 冒頭の節見出しは bare text にせず、必ず `**核心・結論**` または Markdown 見出し（`#` / `##` / `###`）で始める。
- plain text の `核心・結論` だけを単独行で置く形は禁止。
- 引用ブロックには逐語引用だけを書く。説明や注釈は引用ブロック外に出す。
- 要点は箇条書きにせず、3〜6 文の短い段落にする。
- 実務助言や行動提案は禁止。問いへの接続は構造対応として述べる。

## 5. 参照形式
- 各項目末尾に 1 回だけ、validator 互換の 1 行参照を付ける。
- 形式は `（参照：<実ファイル名>|<卦名> - <項目名>）`。
- 解釈の集約参照は `（参照：<実ファイル名>|<卦名>）`。
- `<実ファイル名>` は `## Citation Filenames` に出ている相対パスをそのまま使う。
- `34_雷天大壮.md` のような basename だけへの短縮は禁止。`honda_wataru/34_雷天大壮.md` のようにサブディレクトリ付きで書く。
- ワイルドカード、ID 形式、ツール由来表記は出さない。
