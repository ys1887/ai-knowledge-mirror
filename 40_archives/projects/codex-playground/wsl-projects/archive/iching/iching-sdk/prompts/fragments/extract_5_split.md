## EXTRACT 5-hexagram structure (split profile)

この節は `[TEMPLATE:EX_5]` の split profile に適用する。
- 5卦モードでは、本卦を軸に `変爻` `之卦` `互卦` `錯卦` `綜卦` を必要に応じて組み合わせる。
- active profile の source 系統だけで完結させる。別系統 source を前提にした二本立て解釈は作らない。
- `互卦` `錯卦` `綜卦` は、入力に卦名があるものだけ出す。
- この画面では Markdown の `#` 見出しが強く見えにくいことがあるため、各節見出しは `**見出し名**` の強調文字で出してよい。`#` 見出しだけに依存しない。

### 核心・結論
- 2〜3 文を基本とする。
- 原文引用や「根拠層」はここに書かない。

### 本卦（<卦名>）
- split profile では、選択済み section files に含まれる項目だけを使う。
- 通常は `卦辞` `彖伝` `大象伝` を中心に扱う。

### 変爻（<初爻/2爻/3爻/4爻/5爻/上爻>）
- `変爻：なし` の場合でも `**変爻**` 節は必ず出す。
- `変爻：なし` の場合は、本文を `今回は変爻がないため、本卦全体の意味を主として読みます。` に固定し、変爻由来の引用ブロックは置かない。
- 変爻がある場合は `**変爻（<変爻>）**` 形式で出す。
- 変爻が複数ある場合は、`**変爻（<変爻>）**` 節を変爻ごとに並べる。
- 爻辞は必須。
- 象曰は取得できた場合のみ含める。

### 之卦・互卦・錯卦・綜卦
- 入力にある補助卦だけを出す。
- 補助卦では、卦全体の役割が分かる段階まで短く説明する。
- 補助卦名が入力にあっても、selected sections に根拠が無い内容は膨らませない。
- 補助卦を出す場合の参照形式は `（参照：<論理 citation ファイル>|<卦名> - <項目名>）` にそろえる。

### 文言伝
- 乾為天または坤為地で、selected sections に存在が確認できた場合のみ出す。

### 解釈
- 最終段は `**解釈**` の 1 本にする。
- 本卦・変爻・補助卦を、active profile の source だけで束ねる。
- 補助卦ありでも `総合解釈` へ別名で逃がさず、この節でまとめる。
- 末尾では、本卦・変爻・補助卦のうち実際に扱った卦を `1 卦 1 行` で列挙してよい。
- 形式は各行とも `（参照：<論理 citation ファイル>|<卦名>）` を使う。

```md
**解釈**
中くらいの長さの解釈

（参照：<論理 citation ファイル>|<卦名>）
（参照：<論理 citation ファイル>|<卦名>）
```

### 不足時
- selected sections に必要箇所が足りないなら、不足報告のみで止める。
