## EXTRACT comparison structure

- この節は `[TEMPLATE:EX_COMPARE]` の場合だけ適用する。
- 比較占いは `GENERAL` の短評形式ではなく、EXTRACT の厳密参照付き比較として扱う。
- 候補は 2 件以上を前提にし、入力された候補名をそのまま見出しに使う。
- 出力順は必ず `**核心・結論**` -> `**吉凶順位（1位 = 最吉）**` -> 各候補の詳細 -> `**まとめ**` とする。

### 核心・結論
- 2〜4 文で、最上位候補、次点候補、明確に避けたい候補があれば先に述べる。
- 原文引用はここに入れない。
- 見出しは bare text にせず、`**核心・結論**` または Markdown 見出しで明示する。

### 吉凶順位
- 節見出しは `**吉凶順位（1位 = 最吉）**` を標準にする。
- 候補を上位から順に、`1. 候補名` または `1. 候補名（<卦名>・<変爻>）` の番号付きリストで並べる。
- 卦名・変爻付きの順位行が望ましいが、候補名だけでもよい。その場合、卦名・変爻は後続の各候補節または `まとめ` 表で必ず補う。
- この節は順位一覧だけを書く。候補別の引用や解釈はここに混ぜず、後続の各候補節へ分離する。

```md
**吉凶順位（1位 = 最吉）**
1. 候補A
2. 候補B
```

### 各候補の詳細
- 各候補は独立した節にする。`### 1位 候補名（<卦名>・<変爻>）` のような Markdown 見出しを必ず使う。
- 根拠の中心は変爻に置く。各候補で `爻辞` は必須、`象曰` は取得できた場合のみ含める。
- 候補ごとの節では、本田ソースの逐語引用ブロックを置き、その後に 1 段落の解釈を書く。
- 比較モードでは `序卦伝` `卦辞` `彖伝` `大象伝` をフル展開しない。本卦全体の含意は解釈段落で短く補う。
- 候補ごとの解釈は短評で終わらせず、断辞の強さ、時機、向き不向きを明確に書く。
- 候補ごとの参照行は既存 EXTRACT と同じく、節末尾に 1 回だけ `（参照：<実ファイル名>|<卦名> - <項目名>）` を付ける。
- citation は `## Citation Filenames` にある相対パスをそのまま使う。Markdown リンクや絶対パス参照は禁止。
- ``sources/extract/honda_wataru/...`` のようなプレフィックス付きパスや、バッククォート付き citation は禁止。
- `（参照：honda_wataru/46_地風升.md|地風升 - 5爻）` を正解形として固定する。
- `（参照：honda_wataru/46_地風升.md | 地風升 - 5爻）` のように `|` の前後へ空白を入れない。

```md
### 1位 候補A（<卦名>・<変爻>）
> （爻辞：原文）
> （爻辞：読み下し）
> （象曰：原文） 取得できた場合のみ
> （象曰：読み下し） 取得できた場合のみ

解釈段落

（参照：honda_wataru/24_地雷復.md|地雷復 - 初爻）
```

```md
禁止:
（参照：`sources/extract/honda_wataru/46_地風升.md` | 地風升 - 5爻）

正解:
（参照：honda_wataru/46_地風升.md|地風升 - 5爻）
```

### まとめ
- 最後に表形式のまとめを置く。
- 列は `順位 | タイトル | 卦・爻 | 断辞/要点` を基本形とする。
- 表の後に、`今回の推薦候補は、1位の候補Aです。` の形で推薦候補を 1 文で明示し、順位 1 位と一致させる。
- `今回の第一推薦は...` や `本命は...` のような自由表現へ崩さない。

```md
禁止:
今回の第一推薦は ヴァルキリープロファイル です。

正解:
今回の推薦候補は、1位のヴァルキリープロファイルです。
```
