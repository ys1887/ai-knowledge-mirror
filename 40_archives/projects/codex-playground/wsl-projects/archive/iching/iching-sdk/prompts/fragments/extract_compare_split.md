## EXTRACT comparison structure (split profile)

- この節は `[TEMPLATE:EX_COMPARE]` の split profile に適用する。
- 比較占いは EXTRACT の厳密参照付き比較として扱う。
- active profile の source 系統だけで完結させる。
- 候補は 2 件以上を前提にし、入力された候補名をそのまま見出しに使う。
- 出力順は必ず `**核心・結論**` -> `**吉凶順位（1位 = 最吉）**` -> 各候補の詳細 -> `**まとめ**` とする。

### 核心・結論
- 2〜4 文で、最上位候補、次点候補、明確に避けたい候補があれば先に述べる。
- 原文引用はここに入れない。

### 吉凶順位
- 候補を上位から順に、`1. 候補名` または `1. 候補名（<卦名>・<変爻>）` の番号付きリストで並べる。
- この節は順位一覧だけを書く。候補別の引用や解釈はここに混ぜない。

### 各候補の詳細
- 各候補は独立した節にする。`### 1位 候補名（<卦名>・<変爻>）` のような Markdown 見出しを必ず使う。
- 根拠の中心は変爻に置く。各候補で `爻辞` は必須、`象曰` は取得できた場合のみ含める。
- 比較モードでは `序卦伝` `卦辞` `彖伝` `大象伝` をフル展開しない。本卦全体の含意は解釈段落で短く補う。
- 候補ごとの参照行は節末尾に 1 回だけ `（参照：<論理 citation ファイル>|<卦名> - <項目名>）` を付ける。
- citation は `## Citation Filenames` にある相対パスをそのまま使う。Markdown リンクや絶対パス参照は禁止。
- split section path や split source root 配下の実 path を citation に使ってはいけない。

```md
### 1位 候補A（<卦名>・<変爻>）
> （爻辞：原文）
> （爻辞：読み下し）
> （象曰：原文） 取得できた場合のみ
> （象曰：読み下し） 取得できた場合のみ

解釈段落

（参照：<論理 citation ファイル>|<卦名> - <項目名>）
```

### まとめ
- 最後に表形式のまとめを置く。
- 列は `順位 | タイトル | 卦・爻 | 断辞/要点` を基本形とする。
- 表の後に、`今回の推薦候補は、1位の候補Aです。` の形で推薦候補を 1 文で明示し、順位 1 位と一致させる。
