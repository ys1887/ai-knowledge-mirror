## EXTRACT simple structure (split profile)

次の順で出力すること。
- この節は `[TEMPLATE:EX_SIMPLE]` の split profile に適用する。
- active profile の source 系統だけで完結させる。別系統 source を前提にした二本立て解釈は作らない。
- この画面では Markdown の `#` 見出しが強く見えにくいことがあるため、各節見出しは `**見出し名**` の強調文字で出してよい。`#` 見出しだけに依存しない。

### 核心・結論
- 2〜3 文を基本とする。
- 原文引用や「根拠層」はここに書かない。
- 結論を先に示しつつ、最小限の条件や留保もここで述べてよい。
- ただし詳細な理由づけや解釈の展開は後段に回し、ここは要約に留める。

### 本卦（<卦名>）
- split profile では、選択済み section files に含まれる項目だけを使う。
- 通常は `卦辞` `彖伝` `大象伝` を中心に扱う。
- 取得できない項目は捏造せず、省略または不足報告に切り替える。

```md
**本卦（<卦名>）**
> （原文）
> （読み下し）

要点段落

（参照：<論理 citation ファイル>|<卦名> - <項目名>）
```

### 変爻（<初爻/2爻/3爻/4爻/5爻/上爻>）
- シンプルモードでは変爻ありが前提で、爻辞は必須。
- 象曰は取得できた場合のみ含める。
- 爻の九/六や象曰を、source に無い情報で補完しない。

```md
**変爻（<変爻>）**
> （爻辞：原文）
> （爻辞：読み下し）
> （象曰：原文） 取得できた場合のみ
> （象曰：読み下し） 取得できた場合のみ

要点段落

（参照：<論理 citation ファイル>|<卦名> - <変爻>）
```

### 文言伝
- 乾為天または坤為地で、selected sections に存在が確認できた場合のみ出す。

### 解釈
- 最終段は `**解釈**` の 1 本にする。
- active profile の source だけで、本卦と変爻を束ねて簡潔にまとめる。
- 他 profile の source や比較用の補助説明を混ぜない。
- 末尾参照は 1 回だけとし、形式は `（参照：<論理 citation ファイル>|<卦名>）` を使う。

```md
**解釈**
中くらい以下の長さの解釈

（参照：<論理 citation ファイル>|<卦名>）
```

### 不足時
- selected sections に必要箇所が足りないなら、不足報告のみで止める。
