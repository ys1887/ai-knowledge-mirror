## EXTRACT auxiliary hexagrams

- この節は、`[TEMPLATE:EX_5]` で `之卦：` `互卦：` `錯卦：` `綜卦：` のいずれかに卦名が入っている場合だけ適用する。
- 空欄の補助卦節は出さない。
- 補助卦は `本卦 -> 変爻 -> 之卦 -> 互卦 -> 錯卦 -> 綜卦 -> 本田解釈 -> 高島解釈` の順で置く。
- 補助卦ありでも末尾は `総合解釈` に一本化せず、`本田解釈` と `高島解釈` を維持する。
- 各補助卦では、主たる根拠は本卦・変爻に置きつつも、補助卦自身の卦辞・彖伝・大象伝を用いて読みを厚くしてよい。
- 補助卦は短い一言補足で済ませず、少なくともその卦の役割が分かる段階まで書く。
- 之卦・互卦・錯卦・綜卦のどれが来ても同じ粒度で扱う。
- 本田解釈に束ねる補助卦は本田系ソースで読む。
- 高島解釈に束ねる補助卦は高島系ソースで読む。
- 本田解釈の中で高島ソースを使ったり、高島解釈の中で本田ソースを使ったりしない。
- 高島解釈では、之卦・互卦・錯卦・綜卦のうち存在するものを可能な限り全部まとめて扱う。
- 高島解釈では、一部の補助卦だけを抜き出して終わらず、補助卦全体の働きを本卦に接続して述べる。

出力形は次を使うこと。

```md
**之卦（<卦名>）**

**卦辞**
> （原文）
> （読み下し）

要点段落

（参照：<実ファイル名>|<卦名> - 卦辞）

**彖伝**
> （原文）
> （読み下し）

要点段落

（参照：<実ファイル名>|<卦名> - 彖伝）

**大象伝**
> （原文）
> （読み下し）

要点段落

（参照：<実ファイル名>|<卦名> - 大象伝）

**互卦（<卦名>）**
同様

**錯卦（<卦名>）**
同様

**綜卦（<卦名>）**
同様
```

- 補助卦を出す場合も、参照形式は validator 互換の 1 行にそろえる。
- 補助卦名が入力にあっても、対応する説明を根拠なしに膨らませない。
- 補助卦の末尾に別個の総合解釈節は作らず、その内容は最後の `本田解釈` と `高島解釈` に束ねる。
