# ekikyo-sdk-legacy

このリポジトリは、旧 `ekikyo-sdk` の内容をそのまま残した legacy スナップショットです。  
現在の主力 SDK は [iching-sdk](/home/ys/projects/iching/iching-sdk/README.md) です。

## 位置づけ

- 旧 SDK 実験の保管場所です
- 新規運用は行いません
- 参照が必要なときだけ使います

## 主な中身

- `iching_sdk/`
- `prompts/`
- `rules/`
- `templates/`
- `tests/`

## 補足

- 旧 `ekikyo-sdk` skill はこの legacy 版の起動先としては使いません
- 現行の SDK 運用は [iching-sdk](/home/ys/projects/iching/iching-sdk/README.md) を参照してください
