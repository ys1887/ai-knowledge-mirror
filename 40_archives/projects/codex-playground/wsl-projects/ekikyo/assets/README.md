# Assets Layout

This directory is organized around one authoritative source set and one archive layer.

## Primary Sources

- `honka.md`
  - Source-of-truth for hexagram-level original text, readings, and hiragana lines.
- `koji.md`
  - Source-of-truth for changing-line original text, readings, and hiragana lines.
- `高島易断占例.md`
  - Source-of-truth for reference case excerpts.
- `takashima/`
  - Source-of-truth for Takashima interpretation text.

## Originals

- `originals/takashima_interp/`
  - Imported or reference-only upstream material.
  - Keep these files separate from runtime-facing canonical sources.
