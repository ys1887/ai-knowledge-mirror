# FirePanel

Fire HD 8 のSilkブラウザから、Todoistのカレンダーフィードに載るタスクとWindows 11 PCのCPU・メモリ使用率、C:・E:の容量を見て、登録したアプリを起動する試作版です。画面は横向きの1280×800を中心に設計しています。下段はアプリ6枠と全画面ボタン1枠の一列です。アプリの起動先を登録するまでは押せません。

## 必要なもの

- Windows 11、Python 3.12以降（`py` コマンドが使えること）
- Fire HDとPCが同じ家庭内Wi-Fiに接続できること
- Pythonパッケージ: Flask、psutil、Waitress、icalendar、recurring-ical-events、python-dateutil（`requirements.txt`）

Fire HD側にアプリの追加は不要です。Fire OSの変更や管理者権限も不要です。Todoist表示にはPCからTodoistへのインターネット接続が必要です。

## 最初の準備

PowerShellでこのフォルダを開き、次を実行します。

```powershell
py -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe settings.py
```

設定ウィンドウで「合言葉を設定・変更」を押し、8文字以上の合言葉を保存してください。6つのアプリボタンは、名前と起動先の `.exe` または `.lnk` ファイルを後から指定できます。空欄のボタンは無効です。「設定を保存」を押すと、設定は `data/settings.json`、認証情報は `data/auth.json` に保存されます。`data/` はGitの対象外です。合言葉そのものは保存しません。旧版の8枠の設定は読み込めます。7・8枠目の登録内容は保存時にも保持されますが、画面には表示されません。

初回準備後は `open-settings.cmd` をダブルクリックして設定ウィンドウを開けます。

## Windows PCで確認する

待受IPが初期値 `127.0.0.1` のままなら、次を実行します。

```powershell
.\.venv\Scripts\python.exe server.py
```

PCのブラウザで `http://127.0.0.1:8765/` を開き、合言葉を入力します。CPU・メモリの数値とバーは約2.5秒ごとに更新されます。右上の「更新」でC:・E:の容量、PCの応答時間、Todoistを取り直せます。容量・応答の最終更新日時は「PC情報」の下に表示します。応答時間は更新要求の往復時間で、回線速度テストやping値ではありません。容量は10進のGBで「使用量 / 総容量」と表示します。サーバーはPowerShellで `Ctrl+C` を押すと終了します。
次回からは `start-panel.cmd` をダブルクリックして起動することもできます。その場合、開いた画面を閉じるとサーバーは終了します。

## Fire HDから接続する

1. PowerShellで `ipconfig` を実行し、家庭内ネットワークに接続しているPCのIPv4アドレスを確認します。
2. `settings.py` の設定ウィンドウで「PCの待受IP」をそのアドレスに変更し、保存します。`0.0.0.0` のような全ネットワーク向け待受は使用できません。
3. サーバーを再起動します。Fire HDのSilkブラウザで `http://PCのIPv4アドレス:8765/` を開きます。
4. 初回に合言葉を入力します。ブラウザのセッションが続く間は再入力不要です。

下段右下の「全画面」をタップすると全画面表示を試せます。戻すときは同じ位置の「全画面を終了」をタップします。Silkで切り替えられない場合は、画面にエラーを表示します。日付と時計はFire HD側の時刻を表示します。

Windowsファイアウォールが接続を止める場合があります。**このプロジェクトはファイアウォール設定を自動変更しません。** 許可する場合は、Windowsのプライベートネットワークだけを対象にし、パブリックネットワークやインターネットには公開しないでください。

## Todoistのタスクを表示する

TodoistのWeb版またはデスクトップ版で、設定 → 連携 → 「カレンダー購読URL（iCal）」からURLをコピーし、FirePanelの設定ウィンドウに貼り付けて保存します。特定プロジェクトだけを表示する場合は、そのプロジェクトの「プロジェクトカレンダーフィード」URLを使えます。サーバーを再起動し、Fire HDの画面を再読み込みしてください。URL未設定でもPC情報とアプリボタンは使用できます。

TodoistのURLはPC側の `data/settings.json` にだけ保存し、ブラウザには渡しません。URLを他人に渡さず、設定ファイルも共有しないでください。FirePanelは5分ごとに取得し、手動の「更新」は最短30秒間隔で再取得します。失敗時は前回取得した一覧を残し、取得失敗を表示します。表示は読み取り専用です。

中央左には今日のタスクを最大5件表示します。今日の項目がない場合は今後30日以内の次の項目を最大5件表示します。Todoistのカレンダーフィードに含まれない日付なしのタスクは表示できません。完了したタスクはフィードから除かれます。

## ボタンを入れ替える

Windowsで `settings.py` を再度開き、ボタン名と起動先を選んで保存します。設定ファイルを手で編集する必要はありません。サーバーを再起動し、Fire HDの画面を再読み込みすると反映されます。現在選べる起動先は `.exe` と `.lnk` のファイルです。ストアアプリなど、ファイルとして選べないアプリの登録には未対応です。

起動操作は登録済みのパスだけを使います。Fire HD側からコマンドやパスを送る仕組みはありません。アプリはサーバーを起動したWindowsユーザーの権限で起動します。

## セキュリティ上の範囲

合言葉によるログイン、操作要求の確認、5回失敗後の一時制限を設けています。家庭内LAN上のHTTP通信は暗号化されません。同じネットワーク上で通信を盗み見られる状況への対策が必要なら、HTTPSを導入する構成を別途検討してください。信頼できないWi-Fiでは使わないでください。Flaskの開発用サーバーは使わず、Windowsで動くWaitressから配信します。
