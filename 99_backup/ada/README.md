# backup（エイダの設定ファイルの復旧用コピー）

エイダ（Muse 側）の設定ファイルの全文コピーです。2026-11-09 に、利用者の意向（知識ベースを共有だけでなく復旧にも使えるようにする）を受けて置きました。

## 中身

- SOUL.md … 人格・口調の正本の写し
- IDENTITY.md … 名称（正式名称エイダ、表示名 Pod）の写し
- AGENTS.md … 運用の取り決めと過去の教訓の写し

MEMORY.md（利用者の長期記憶）は、利用者自身の情報の集まりなのでここには置いていません。

## 復旧のしかた

1. Muse 側の設定が初期化・消失したときに、このフォルダの各ファイルを Muse 側のホーム直下へ同じ名前で戻します
2. 戻す前に、この README と各ファイルの日付（最終同期日）を確認します。古い写しで新しい設定を上書きしないためです
3. 戻したあとは、表示名などの見た目が元どおりかを確認します

## 同期の約束

- 正本は Muse 側です。この写しは実行許可や指示にはなりません
- 原本を変更したら、その都度この写しも更新します

- 最終同期日：2026-11-09
