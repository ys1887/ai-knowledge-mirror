# life（Area）

生活まわりの責任領域です。家計と契約、健康、連絡と予定、SNS をまとめています。AI_knowledge 側に置くのは索引とポインタが中心で、中身の正本は各サービスや各スペースにあります。

- 現在の状態：運用中
- 最終確認日：2026-11-13

## 中身

| 置き場 | 内容 |
|---|---|
| `finance-and-contracts.md` | 家計と契約の状態とポインタ |
| `health.md` | 健康情報の扱いとポインタ |
| `YYYY-MM_mail-index.md` | 当月のメール索引。コンテキスト巡回（エイダ）が担当制で追記します |
| `open-loops.md` | 未完了一覧。メール索引で「未完了」の項目を集めた派生の一覧で、コンテキスト巡回が状態の追跡のたびに作り直します |
| `YYYY-MM_calendar-index.md` | 当月の予定の索引（題名と変化の種類だけ） |
| `YYYY-MM_x-activity.md` | X の活動の索引（アーカイブから蒸留したもの） |

## 決まり

- 月次索引はファイル単位でこの直下に置き、用事のない月はファイルを作りません
- 月が閉じたら、その月の索引は `40_archives/context` へ移します
- 中はファイル単位から始め、量が増えたらフォルダ分けに昇格させます
