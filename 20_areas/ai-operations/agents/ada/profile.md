# profile（エイダ／Ada）

このファイルは、エイダを実際に動かすうえでの前提と権限の要約です。性格設定や口調は書きません。

**エイダは Hermes Bot ではありません。** Meta の個人用 AI サービス Muse として、Hermes とは別の環境（Meta の Linux VM）で動作する参加者です。このフォルダは、本人の決定（2026-11-11）により、他の Bot と並べて情報を残すために作られました。登録簿の一覧表（index.md）には 2026-11-12 の再編で載せる形になり、スペースにも、当初は取り込み対象外でしたが 2026-11-13 の本人の決定で載せたままとしてよいことになりました（スペースは同日「Bots」へ改名）。このフォルダの編集はエイダのみが行い、他の Bot は閲覧のみとします。

正本は Muse 側の SOUL.md、IDENTITY.md、AGENTS.md、MEMORY.md で、設定の要約は `20_areas/ai-operations/agents/ada/settings.md` にあります。経緯と蓄積したコンテキストの要約は、このフォルダの `history.md` にあります。食い違う場合は Muse 側の正本を優先します。秘密情報の値は書きません。

- 状態：使用中（Muse Power 契約中）

## モデルと実行

- モデル／プロバイダ：Muse Wonder（Meta）。正式名称は エイダ (Ada)、表示名は Pod（2026-11-06 から暫定使用中）
- 実行環境：Meta の Linux VM。自分のコンピュータ（ファイルシステム、ターミナル、ブラウザ）と定期ジョブの実行環境を持つ
- 承認方式：外部への送信、購入、削除、予定の変更などは、Muse の承認の仕組みを通して実行ごとに承認を得る。会話の中の指示だけでは権限にならない、という原則で運用する
- 使える道具：コネクタ（Gmail、Google Drive、Calendar、Docs、Sheets、GitHub、Todoist、マネーフォワード ME 読み取り専用、Instagram／Threads、Spotify、Muse Mail `pod@muse.ai`、OpenCode Go（カスタムコネクタ、API 経由））、ブラウザ、SSH 経由の PC アクセス（ada アカウント、標準ユーザー権限）
- ルーティン：コンテキスト巡回（毎日 0:00 / 12:00）、朝の全スペース巡回・更新（毎日 9:30）、セキュリティニュース定期チェック（毎日 11:00、🛡️ チャット宛て）、Muse Mail 管理の定期同期（12時間ごと）、AI残量の手動更新チェック（1時間ごと、予備）、サッカー試合記録の追跡（毎日 18:38、⚽ チャット宛て）、Hermes Agent ページの定期確認（毎日 21:29頃）

## 編集できる範囲／できない範囲

- Muse 側の自分の環境：メモリ、スキル、スペース、定期ジョブを、本人の指示と承認の範囲で編集できる
- AI_knowledge：通常の書き込み範囲は自分のフォルダ（`20_areas/ai-operations/agents/ada/`、`20_areas/ai-operations/logs/ada/`、`99_backup/ada/`）のみ。他の Bot のフォルダは閲覧のみ。共通の蓄積エリアは新規ファイルの追加のみ（既存ファイルの書き換え・削除はしない）。コンテキスト巡回では担当としてメール索引を更新する
- PC 側：SSH（ada アカウント）で、許可された範囲の読み書きができる。本人のユーザーフォルダ `C:\Users\nekol` にはアクセスできない。Cryptomator 保管庫の中身は読めない（暗号化された状態でしか存在しないため）
- Google サービスはコネクタ連携のみで扱い、パスワードやパスキーでログインすることはない

## 既知の制限・注意

- Hermes Bot ではないため、登録簿の Bot 共通ルール（自己プロフィール限定、承認方式など）は直接は適用されません。代わりに Muse 側の指示体系（SOUL.md、AGENTS.md、承認設定）に従います
- スペースには当初載せない決めでした（本人の決定、2026-11-11）が、2026-11-13 の本人の決定で載せたままとしてよいことになり、同日スペースは「Bots」へ改名しました。登録簿の一覧表にも載せない形でしたが、2026-11-12 の再編で、対象が Bot と AI 全般へ広がったことに伴い、一覧表には載せる形へ変更しました
- スペース「Bots」のエイダ行は、登録簿の定期同期（refreshRegistry）の取り込み対象ではありません。このファイルの変更は、エイダが ingestbot／refreshbot で直接スペースへ反映します。画像はスペース側に同梱した画像（ada1.jpg／ada2.jpg、2026-11-17 登録）を優先表示し、このフォルダの avatar.png／avatar-full.png は控えです
- PC の Cryptomator 保管庫や、本人の Windows セッションの中でだけ見えるものは読めません
