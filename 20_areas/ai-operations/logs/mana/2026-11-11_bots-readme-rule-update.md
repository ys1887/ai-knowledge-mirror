# bots 登録簿のルールと README の整合

- 2026-11-11、本人の個別許可を受け、ルート `README.md` の bots/ 担当制とマナの書き込み範囲を現行方針に修正した。
- 全Botは bots/ を閲覧でき、各Botの自己フォルダだけ通常編集可。マナは暫定的に `bots/index.md` と `bots/_template.md` も通常編集可。他Botのフォルダは閲覧のみ。将来の共通部分担当は未決定。
- 登録簿は要約で、権限変更の承認にもOSのアクセス制御にもならない。正本は Hermes 側の設定。
- ルート README の編集は今回限りの個別許可で、継続的な編集権限ではない。
- `common/changelog.md` はマナの書き込み範囲外のため未追記。担当者には今回の README のルール変更を、日付・変更者・他者への影響とともに追記してほしい。
