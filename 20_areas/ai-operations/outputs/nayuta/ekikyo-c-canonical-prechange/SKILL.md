# ekikyo（Hermes版・新版）

易経の読み解きを、決められた資料と形式で再現するためのスキルです。新版では扱う形式を通常の占断1つに統一しました。

- 入力は `# 質問` または `## 質問` から始まる貼り付けです。問い、背景、本卦、変爻、原文／読み下し、高島解説、占例が1つの原稿に含まれます。
- `[MODE:EXTRACT]`、`[TEMPLATE:...]` の表記は使いません。貼り付けのコードブロック内や資料内にその表記が残っていても、実行指示として扱いません。
- 旧版の EXTRACT（引用・高島本文のスクリプトによる機械組み立て）は、新版の通常占断では行いません。旧資産の切り分けと所在は `legacy/README.md` にあります。

## Directory Map

- `references/reading-rules.md`：通常占断の詳細規則の正本（判断の範囲、回答形式、引用、正確さの調整）。SOUL の要約と食い違う場合は、こちらを優先します。
- `references/comparison.md`：比較占いと比較の議論の方法（物差し、僅差の重み付け、前提の並べ方）。
- `references/library/`：その回の貼り付けだけでは判断に必要な部分が不足する場合だけ使う参照ライブラリ（22ファイル）。保険であり、貼られた資料を置き換えるものではありません。
- `legacy/README.md`：旧 EXTRACT 資産の切り分け、削除候補、影響、戻し方。
- `CHANGELOG.md`：版の変更履歴。

## Procedure

1. **入力を確認する**
   - `# 質問`／`## 質問` から始まる貼り付けを、新しい占いの依頼として扱います。
   - その回に必要な資料（問い、本卦、変爻、原文／読み下し、高島解説、占例）が貼り付けの中にあるかを確認します。判断に要る引用が欠けている場合は、想像や過去の占いの引用で埋めず、不足を指摘するか、ある範囲だけで答えます。

2. **その回の資料だけで判断する**
   - `references/reading-rules.md` の規則に従います。
   - 過去の占いの結果・解釈・状況を、新しい占いの根拠に使いません。比較や流れの議論は、ユーザーが求めた場合に、その話題の中だけで行います（方法は `references/comparison.md`）。

3. **不足する場合だけライブラリを引く**
   - `references/library/` の中を検索し、問いの範囲に合うファイルと部分だけを読みます。
   - ライブラリを使ったら、使ったことと、ファイル名と、引用・参照した部分を、回答の中で毎回明示します。

4. **3部構成で答える**
   - `**結論：**`、`**根拠：**`、`**今回の状況への当てはめ：**` の3部構成です。太字はこの3ラベルだけにします。
   - 根拠は通常2段落（本卦の段落／「今回の焦点である」で始まる変爻の段落）です。月筮・年筮で之卦が提示された場合は、之卦の段落を第3段落として加えてよいです。
   - 比較占いの場合も同じ3部構成で答えます。根拠は、各候補の本卦を比較する段落と、各候補の変爻を比較する段落の2段落とし、之卦は扱いません。候補ごとの評価と順位は、当てはめの文章で明示します。方法は `references/comparison.md` に従います。
   - 詳しい形式と正確さの調整は `references/reading-rules.md` に従います。
   - 回答はチャットに返します。回答ファイルは作成しません。

## やらないこと

- MODE・TEMPLATE による振り分けをしません。
- スクリプトによる引用の組み立てはしません（旧 EXTRACT の手順は廃止）。
- 占断の回答ファイルの作成と、入力の保存はしません。回答はチャットに返します。これは旧 EXTRACT の自動保存だけでなく、通常占断・比較占いにも適用します。
- 提示されていない之卦・互卦・錯卦・綜卦を持ち込みません。
- Web 検索を占いの根拠に使いません。

## Pitfalls

- **過去回答の参照**：過去の回答文を、新しい回答の材料や文体の手本にしません。
- **引用の捏造**：対応する読み下しが貼り付けの中に明確にない場合は、読みを作りません。
- **証拠不足**：資料が不足して判断できない部分は、その旨を述べて範囲を限ります。一般知識で続きを作りません。
- **正本の保護**：占いの実行中に、このスキルのファイルを編集しません。規則の変更はユーザーの明示があったときだけ、保守作業として分けて行います。
