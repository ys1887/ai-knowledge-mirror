# 29坎為水

  

6

59風水渙

27山雷頤

30離為火

29坎為水

  

【本卦の基本情報】

  

- **卦名と構成**：坎為水は、上卦が坎、下卦が坎で構成される29番目の卦。

- **卦の図象**：☵☵（坎卦が上下に重なる形）

- **卦辞**：

    - 原文：坎。習坎。有孚。維心亨。行有尚。

    - 解釈（出典：易経）：重なった坎は、それぞれ中心に実（陽）があり、中に信念があることを表す。言い換えれば誠心が貫通する。不退転の信念を持って行動すれば、人から褒められるだけの功績があるだろう[^1_2]。

- **彖伝**：

    - 原文：習坎。重險也。水流而不盈。行險而不失其信。維心亨。乃以剛中也。行有尚。往有功也。天險不可升也。地險山川丘陵也。王公設險以守其國。險之時用大矣哉。

    - 解釈（出典：易経）：坎が重なることは、険難が重なることを意味する。水は流れても溢れることなく、危険な場所を通っても本質を失わない。心が貫通するのは中央に強い線（陽）があるからである。行動すれば尊ばれるというのは、前進すれば功績があるということだ[^1_1]。

- **大象伝**：

    - 原文：水洊至。習坎。君子以常德行。習教事。

    - 解釈（出典：易経）：水が絶えず流れ続けることが重なった坎の象である。君子はこれにならって、徳行を常に保ち、教えを実践する[^1_1]。

- **本卦が示す状況の全体像**（出典：現代易占詳解）：もともと坎為水は困難の卦。水雷屯、水山蹇、沢水困と並べられる四難卦の一つ。坎が一つだけでも苦しむのに、さらに坎が重なった卦であるから、非常な苦しみとなる。しかし最後まであきらめずに信念を貫くことができれば、目的を達成することはできる[^1_2]。

  

【変爻の解釈】

  

[爻の位置: 6] の解釈（上爻: 上六）

  

- **爻辞本文**：遯用徽纆。置于叢棘。三歲不得。凶。

- **象曰（小象伝）**：上六失道。凶三歲也。

- **解釈**（出典：現代易占詳解）：繰り返し縄で縛られて、いばらの草むらに置いて行かれるようなもの。三年間は出られない。凶である[^1_2]。

- **変爻の意味**（出典：現代易占詳解）：三年は困難から抜け出せない。何をしても逆効果となり、全く身動きが取れない時。努力をしても報われない。ただただ耐え忍ぶのみ[^1_2]。

  

【派生卦の解釈】

  

**之卦**：風水渙

  

- **卦名と構成**：風水渙は、上卦が巽（風）、下卦が坎（水）で構成される。

- **卦辞**：

    - 原文：渙は、亨る。王有廟に仮る。大川を渉るに利あり。貞しきに利あり。

    - 解釈（出典：易経）：渙では、願いことが叶う。王が廟に至ることで、渙散していた先祖の霊魂が再び結集するだろう。大きな川を渡るような冒険をしても利益がある。ただし、正道を守ることができる場合にのみ利益がある[^1_3]。

- **本卦との関係性**（出典：神戸の易者 黄玉の易占い）：

    - 本卦（坎為水）の困難や苦しみから、之卦（風水渙）では精神的な悩みが解消される。風水渙は、精神的な意味でのこだわりが解ける。悩み、トラウマ、コンプレックスなど、だいたい良い意味での解消となる[^1_4]。

  

**互卦**：山雷頤

  

- **卦名と構成**：山雷頤は、上卦が艮（山）、下卦が震（雷）で構成される。

- **卦辞**：

    - 原文：頤，貞吉。觀頤自求口實。

    - 解釈（出典：易経）：頤は、観察別人如何養生，以求得自己口頰的充実。如果正確的話，吉[^1_6]。

- **本卦との関係性**：

    - 山雷頤は養生と修養を象徴する卦であり、本卦（坎為水）の困難な状況の中で、いかに自己を養い、修養するかを示唆している[^1_5][^1_6]。

  

**錯卦**：離為火

  

- **卦名と構成**：離為火は、上卦が離、下卦が離で構成される。

- **卦辞**：

    - 原文：離，利貞。亨。畜牝牛吉。

    - 解釈（出典：易経）：離卦は光明と依附を象徴し、正道を守ることが有利であり、通じる。母牛を飼うことは吉である[^1_8]。

- **本卦との関係性**：

    - 本卦（坎為水）が困難と暗闇を象徴するのに対し、錯卦（離為火）は光明と明るさを象徴する。坎が内に実（陽）を持ち外が虚（陰）であるのに対し、離は内が虚で外が実という正反対の構造を持つ[^1_7][^1_8]。

  

**綜卦**：坎為水

  

- **卦名と構成**：綜卦も坎為水であり、上下とも坎卦である。

- **本卦との関係性**：

    - 本卦と綜卦が同じであるため、困難や苦しみが継続することを示唆している。

  

【総合解釈と実践的アドバイス】

  

- **状況の総合分析**：

    - 現在の状況（本卦）：坎為水は重なる困難を示し、特に上爻の変爻は最も困難な状態を表している。三年間は困難から抜け出せない状況にある[^1_2]。

    - 潜在的な影響（互卦）：山雷頤は、困難の中でも自己を養い、修養することの重要性を示唆している[^1_5][^1_6]。

    - 対照的な視点（錯卦）：離為火は、現在の暗闇と対照的な光明を象徴し、将来的には明るさが訪れる可能性を示している[^1_7][^1_8]。

    - 変化の方向性（之卦）：風水渙は、精神的な悩みや苦しみが解消される方向に向かうことを示している[^1_3][^1_4]。

- **実践的アドバイス**：

    - **行動の指針**：現状では積極的な行動は控え、耐え忍ぶことに集中する。不退転の信念を持ち続けることが重要[^1_2]。

    - **タイミングと方法**：今は新しいことを始めるタイミングではなく、現状維持に努める時期。質素な生活を心がけ、内面の修養に時間を使うべき[^1_2][^1_6]。

    - **注意点（リスクや障害）**：病難、水難、色難、詐欺などに注意が必要。特に感情に流されて誤った判断をしないよう警戒する[^1_2]。

    - **期待できる成果**：当面は困難が続くが、信念を貫き通せば、最終的には精神的な悩みが解消され、状況が好転する可能性がある[^1_2][^1_3][^1_4]。

# どう生きるか問うたらこの卦と変爻を得た。

  

回答はわかりやすい。困難が続くので耐えろ。ただしその間に努力をしろ。やがて光明がある。大雑把だがこういう解釈でよいか？

また、三年間困難が続くとあるが、原文にもあるが、これは文字通り3年なのか、それとも何かの暗示なのか？

  

はい、あなたの解釈は大筋で正しいです。坎為水の卦と上六の変爻は、確かに困難が続く中で耐え忍び、内面の修養に努めることの重要性を示しています。そして最終的には風水渙の卦が示すように、精神的な悩みが解消される方向に向かうでしょう。

  

「三歲（三年）」については、易経の解釈では二通りの見方があります：

  

1. **文字通りの三年間**：実際の時間として三年間困難が続くという解釈。これは最も直接的な理解です。

2. **象徴的な意味**：「三」という数字は易経において完成や一つのサイクルを表すことがあります。つまり「一定の長い期間」や「ある段階が完全に終わるまで」という意味で解釈することもできます。

  

伝統的な易学では、この「三歲」は必ずしも文字通りの3年間ではなく、困難が長期間続くことを強調する表現とも考えられています。また、占いの対象となる事柄の性質によって、その「三年」の意味合いは変わってくるとも言われています。

  

「どう生きるか」という根本的な問いに対しては、この卦は：

  

- 困難や障害は避けられないものとして受け入れること

- 外面的な成功よりも内面の修養に重きを置くこと

- 忍耐強く自分の信念を貫くこと

- 時期が来れば、精神的な悩みから解放される

  

という生き方の指針を示していると解釈できます。「三年」という期間は、あなたの人生における一つの重要な段階を表している可能性があります。

# 今どうするか、という質問ではなく、私のような人間はどう生きるか、と問うたので、この場合は現状が3年続くというよりも、困難な時期が一段落するまでこのように生きろ、というようなアドバイスと受け取ったほうがいいか？

  

現状はたしかに大変だが、現状をどうするか、という問いではない。しかし現状に当てはまる回答でもあった。だが、質問は現状のことではなくもっと漠然としていて期間を今や未来に定めたものでもない。

  

おっしゃる通りです。「どう生きるか」という人生哲学や生き方の指針を問うた質問に対して、この卦と変爻は時期を限定したアドバイスというよりも、人生の姿勢や態度についての根本的な指針を示していると解釈するのが適切でしょう。

  

この場合、「三歲」は文字通りの3年間というよりも、「一つの困難な段階が完全に終わるまで」という象徴的な意味合いで捉えるべきです。つまり、あなたのような人間の生き方として：

  

- 困難や障害に直面したときは、それを避けようとせず、耐え忍ぶ姿勢を持つこと

- 外面的な成功や華やかさよりも、内面の修養と誠実さを重んじること

- どんな状況でも信念を貫き、本質を見失わないこと

- 時に孤独や苦しみを感じても、それを人生の一部として受け入れる強さを持つこと

  

という生き方の本質的な指針を示していると考えられます。

  

坎為水の卦は、水が低きに流れながらも決して本質を失わず、障害物にぶつかっても道を見つけて流れ続けるように、柔軟でありながらも強い意志を持って生きることの大切さを教えています。

  

現状の困難に当てはまる回答だと感じられたのは、おそらく今のあなたの状況が、この卦が示す本質的な生き方の知恵を実践する好機であるからかもしれません。質問は漠然としていても、易経はあなたの人生全体に通じる生き方の知恵を示してくれたと解釈できるでしょう。
