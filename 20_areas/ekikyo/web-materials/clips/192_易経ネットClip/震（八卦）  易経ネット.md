## 震（しん）

| ![震](https://ekikyo.net/photo/64dai/sin.png) | 震は二陰の下に陽が発生し、雷が万物を奮い立たせるという卦です。この卦の象意は、驚き、騒々しい、音や電気に関するもの、動揺、刺激、突進など雷から類推されるものです。驚き騒ぐわりには、実害はないとします。正象は雷、易数は4、属性は震動、奮闘、家族は長男、方位は東です。 |
| --- | --- |

| 象意 | 雷、奮動、発奮、勇敢、発展、成功、驚愕、繁栄、才能、憤怒、発現、独立、地震、感電、応答、速力 |
| --- | --- |
| 季節 | 三月上旬、啓蟄節から春分を経て四月上旬の清明節に至る一か月間。太陽は遠く風は冷たいけれど芽生えの気配がある。 |
| 時間 | 五時から七時までの二時間。 |
| 天象 | 晴、夕立、雷雨、地震 |
| 人象 | 長男、青年、若人、広告宣伝マン、アナウンサー、交換手、電気、楽器関係の人、勇ましい人、騒がしい人、短気の人 |
| 人体 | 肝臓、神経、足 |
| 病象 | 肝臓病、逆上、ヒステリー、神経痛、怪我、けいれん、百旦咳、喘息、リュウマチ、突発的病気、筋肉痛 |
| 相場 | 動く、上昇 |
| 場所 | 放送局、騒がしい所、発電所、広告塔、電気器具店、楽器店、音楽堂、林 |
| 食物 | 寿司、酢の物、柑橘類のすべて、梅干、野菜類、海藻類、果実、筍 |
| 動物 | 龍、鳴く虫 |
| 植物 | レモン、若竹、サボテン、みかん、椿 |
| 物象 | 電気器具、音の出る物、楽器、鈴、電話、広告のちらし、灯火、花火、若者向きの物、新品、木の苗、寿司、銃 |
| 性情 | 明朗で社交家。積極的で早熟、女性には甘いところがある。色難がある。偏愛的で負けず嫌いだが度胸はない。短気で感情的。言葉の上での誤解に苦しむ。 |
