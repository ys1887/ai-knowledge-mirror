## 巽（そん）

| ![巽](https://ekikyo.net/photo/64dai/son.png) | 巽は二陽の下に陰が入りこんでいる象で、風が陽気を吹き飛ばすという卦です。この卦の象意は、風のように四方に伏入するもの、軽いもの、出人りの激しいもの、営業に関するもの（商人、外交員等）、不安定な状態などです。正象は風、易数は5、属性は伏入、家族は長女、方位は東南です。 |
| --- | --- |

| 象意 | 風、出入り、利益、繁盛、柔和、依頼、命令、へつらい、風俗、世間、信用、多欲、薄情、恋愛、交際、不決断 |
| --- | --- |
| 季節 | 四月上旬、清明節から穀雨・立夏・小満・芒種節に至る二か月間。陽気が生成される時。 |
| 時間 | 七時から十一時までの四時間 |
| 天象 | 風吹く、雨降らず |
| 人象 | 長女、セールスマン、商人、旅行者、来客、郵便局の人、迷う人、未婚者 |
| 人体 | 肝臓、呼吸器、腸、股、食道 |
| 病象 | かぜ、呼吸器病、腸疾患、わきが、性病、流行性疾患、肝臓病、一進一退 |
| 相場 | 不安定、下降気味 |
| 場所 | 道路、連絡路、遠い所、飛行場、港、電信関係の所、ポスト、仕上工場、商店 |
| 食物 | うどん・そばなど麺類のすべて、繊維質の野菜、酢の物、柑橘類の果物、ネギなど臭みのある植物、山菜の植物 |
| 動物 | 蛇、鳥、蝶、うなぎ、あなご、太刀魚、トンボ |
| 植物 | 竹、木 |
| 物象 | 扇風機、うちわ、飛行機、木製品、仕上品、帯、糸、紙、そば、線香、香水 |
| 性情 | やさしく、おだやかで、人の世話をよくする。言葉に丸みあり、社交性に富む。決断カに欠け、チャンスをにがす。反省力薄く、愚痴っぽい。うぬぼれは強い。 |
| 雑象 | 交際、世話、友情、信用、商売、風評、遠方、旅行、通信、迷う、行き違い、長い、飛ぶ、縁談、結論、調う、如才ない、風俗、軽挙、とりとめない |
