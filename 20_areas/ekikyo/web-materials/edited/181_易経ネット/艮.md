## 艮（ごん）

| ![艮](https://ekikyo.net/photo/64dai/gon.png) | 艮は下の二陰を上の陽が抑えている象で、山が動かずに万物を止めているという卦です。この卦の象意は、山に関するもの、不動のもの、高い（高尚な）もの、安定、阻止などです。形からみて、城、家、墓、神杜などとします。正象は山、易数は7、属性は静止、家族は少男、方位は東北です。 |
| --- | --- |

| 象意 | 山、静止、丁寧、篤実、敬粛、質朴、高尚、頑固、障害、渋滞、謝絶 |

| 季節 | 二月、立春から雨水を経て三月上旬の啓蟄節までの一か月間。「梅一輪一輪づつの暖かさ」冬から春へ移り動く変わり目のとき。 |
| 時間 | 午前一時から五時までの四時間。 |
| 天象 | 曇 |
| 人象 | 少男、相続人、家族、親戚、知人、同業者、革命家、頑固者、高尚な人、変わり者、欲張り、鉱山関係者、警備係りの人、ホテルマン、倉庫係りの人、後継者 |

| 相場 | 高値で保合 |
| 場所 | 城、土手、石垣、山岳、山林、高山、高台、宿舎、旅館、倉庫、物置小屋、二階、階段、角、玄関、門、出口、椅子、山路、境界、貯蔵所、橋、丘 |

| 性情 | ゴーイングマイウェイ。堅実で、目上の引き立てもあり、実業面で成績を挙げる。欲にとらわれると友人に嫌われて孤立する。七転八起で盛り返す力がある。気分のむら、方針の転換に注意すれば幸せを得られる。好き嫌いは激しい。勝気で勘がよい。 |
