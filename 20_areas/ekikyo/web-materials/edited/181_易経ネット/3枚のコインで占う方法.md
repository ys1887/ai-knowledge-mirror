## 3枚のコインで占う方法

どんなコインでもかまいませんから、三枚用意します。そして最初にどちらがコインの表か裏かを決めておいてください。

一般に言われる表裏にしたがってもいいし、自分で「こちらが表」と決めてもかまいません。当サイトでは100円玉を使用し、桜の花を表、100と書いてある方を裏とします。

そして占いたいことを心の中で念じ、手の中でよく振って、これを投げます。投げるといってもこれはサイコロを振る要領でかまいません。

さて、投げたら下図に従って結果を読みとります。

![](https://ekikyo.net/method/method0.gif)

同じことを六回くり返します。これは易の卦（ [六十四卦](https://ekikyo.net/64ka/00.html) ）というものが六つの部分（爻という）から成り立っているからです。

これを第一回目からだんだん上に積み上げて書いていくと、下図のような卦ができあがります。

![](https://ekikyo.net/method/method.gif)

つまり下から少陰、少陰、老陽、少陽、少陰、少陽ということになるわけです。これを下から、 **初爻、二爻、三爻、四爻、五爻、上爻** と呼びます。（陽を陽爻、陰を陰爻とも呼ぶ）

さて、このうち初爻から三爻までの三つの爻をまとめて **「下卦」** とし、四爻から上爻までをまとめて **「上卦」** とします。つまり三つずつのブロックとして見るわけです。この三つからなるブロックの組み合わせが八通りあり、これが [八卦](https://ekikyo.net/8ka/) （はっか）と呼ばれるもので、易の解釈の基礎になっています。

さて下卦と上卦に分けたら、そのブロックの形を [六十四卦一覧](https://ekikyo.net/64ka/) に照らしあわせます。この一覧表には六十四卦、すなわち易占いの中心をなす基本体系の数字（名前）が出ています。これにそって、いまあなたが出した卦が六十四卦の解釈のどれに当たるかを見るわけです。

まず下卦について見ると、これは 艮に当たります。次に上卦を見るとこれは 離に当たります。そこで艮と離の交差する枠を見ると、そこには「56」という数字があります。この数字が占いの結果であり、六十四卦のうち「56番を見よ」ということなのです。

あなたはこの卦（これを **本卦** とよぶ）の説明を読んで、そこに書かれていることから、自分の問題点を把握し、どうふるまったらいいのか、行動の指針を得ることができます。

56番 [火山旅](https://ekikyo.net/64ka/56.html) の **卦辞** を見ると、「旅に出る。小さな事なら願いはかなう。旅の正しい道を守れば吉。」とあります。これをより深く理解するには、次に **爻辞** を見ます。それを示すのが●印のついた老の陰・陽です。すなわち、この場合は下から3番目となります。

老は、盛りを過ぎそろそろ変化しようとしている特別の意味があります。つまり、爻辞が、今のあなたに対する答えとなります。

それによると、「旅先で宿が火事に遭い、召し使いの若者も行方知れず。危険である。」とあります。それをさらに理解するには、火山旅の卦辞の言葉を吟味し、さらに肉付けをして、いろいろな角度から考えなくてはなりません。

### 之卦

しかし、易が告げるのは本卦だけに止どまりません。下から3番目のこの老陽は、将来逆転し陰となるかもしれない。すなわち今後の展開を暗示するのが之卦（伏卦）です。

![之卦](https://ekikyo.net/method/sika.gif)

最初占って得た卦は、火山旅の三爻です。その之卦（伏卦）は [火地晋](https://ekikyo.net/64ka/35.html) となります。これを易で正式には、「火山旅の三爻変、火地晋に之く」と言います。

之卦は、将来を暗示するものですが、必ずこの状態に移り変わることを示しているものではありません。このような事情が内在していることを示すもの、と受け取ってください。

もちろん、之卦（伏卦）の状態に変わる可能性があるとみることもできますが、裏の事情や注意点を探ることに用いる場合もあります。

なお、●印のついた老陰や老陽がなければ、占いの判断は、本卦の言葉を中心にして、初爻から上爻の爻辞は、そうしたさまざまな可能性をひそめていると解します。

ところで複数の老陰、老陽の場合は、どうすればよいでしょうか。朱子の『易学啓蒙』に、次のようなことが書いてあります。

| 一爻変 | その変爻の爻辞を用いる。 |
| --- | --- |
| 二爻変 | 二つの変爻の爻辞を用い、上を主とする。 |
| 三爻変 | 本卦と之卦の卦辞を用いる。 |
| 四爻変 | 之卦の二つの不変爻の爻辞を用い、下を主とする。 |
| 五爻変 | 之卦の不変爻の爻辞を用いる。 |
| 六爻変 | 之卦の卦辞を用いる。ただし、乾は用九・坤は用六を用いる。 |

しかし実際は、二つの文句が正反対の性質だったりして困りますので、やはり 『春秋左氏伝』にあるように、「二爻以上変ずるときは本卦の卦辞を見る」のが妥当です。

之卦（伏卦）以外にも易にはさまざまな変卦があります。

### 互卦

互卦とは、本卦の二、三、四爻を下段の内卦とし、三、四、五爻を上段の外卦としたものです。占断に当たり、現実を解決する一つの手がかり、また伏されている事情として、得られた本卦とあわせ、照合することにより、より現実的・具体的に占断できます。また、介在するものや状態・内部事情、時間的な進捗状況もみることがあります。

![互卦](https://ekikyo.net/method/goka.gif)

### 裏卦（錯卦）

裏卦（錯卦）とは、本卦の陰爻と陽爻をそっくり裏返しをしたものです。これも一つの占法で、裏面に含まれている動きや生活史、隠されている本心として判断の参考にするものです。

![裏卦](https://ekikyo.net/method/uraka.gif)

### 賓卦（綜卦）

賓卦（綜卦）とは、本卦の六本の爻の上下を百八十度逆転したものです。物事を相手側から見た時の状況を表します。

![賓卦](https://ekikyo.net/method/hinka.gif)
